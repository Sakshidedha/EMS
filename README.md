# Employee Management System Using Python
An Employee Management System (EMS) is a software application designed to streamline and automate various aspects of managing employees within an organization. This application is a Web-based system that can run on a Local Area Network, allowing HR managers and administrators to manage employees from different locations.The system helps organizations reduce manual work, improve accuracy, and enhance productivity.
# Objective
The primary objective of the EMS is to provide a centralized platform where employers can efficiently manage employee details and ensure seamless communication between employees and HR departments.
# Key Features
**Features For HR**

• Login Form: A portal through which HR, Employees, and Administrators can log in securely."

• Employee Records Display – HR can view a well-organized table listing all employee records, including personal details, job roles, and employment status.

**Features For Employees**

• Employee Personal Details View – Employees can securely access and view their personal information, including contact details, job role, and salary.

 • Employee Self-Service Password Management – Allows employees to securely update their passwords through a dedicated interface with authentication validation

**Features For Administrator**

• Employee Registration – The administrator can add new employees by entering their personal details, job role, salary, and other necessary information into the system.

• Employee Record Deletion – Administrators can remove employee records from the system when they are no longer needed, ensuring data accuracy and compliance.

• Employee Details Modification – The administrator can update and edit employee information, including personal details, job role, salary, and other relevant data.

• User-friendly interface to interact with the employee management system.
